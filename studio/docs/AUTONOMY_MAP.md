## Autonomy tiers for Studio (Matt's Oct 26 8:46 AM constraints)
**Tier A — auto-run, no Matt:** research, briefs, drafting, repurposing, EN/FR translation, QA, fact-check, auto-fix loop (max 3), internal L1/L2/L3 audits, scheduling drafts into the internal calendar, analytics ingest of data already provided, reply *drafts*, lead logging, digests.
**Tier B — auto-approve internal, Matt sees in digest:** drafts that pass every gate move to "Ready for Matt" automatically; nothing waits in "pending" for him.
**Tier C — needs Matt's explicit OK (never automated):** posting live, sending any DM/email/reply, buying/spend, settings changes, merging to main, public deploy.
**Timeout / escalation:** a Tier-C item waiting >24 h is flagged "escalated" in the digest and the pipeline keeps working on other items (queue, not a block). A gate failing 3× becomes an Escalation Report (template §4) and the item is parked; the rest proceeds.
